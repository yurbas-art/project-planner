# Project Planner

## Авторизация и MariaDB

Backend запускается отдельно от Vite и использует MariaDB для хранения учетных записей.

1. Убедитесь, что MariaDB запущена.
2. Выполните SQL-схему:

```bash
mariadb -u root -p < server/schema.sql
```

Если база уже была создана ранее, повторно выполните эту команду: она добавит таблицу `tasks` без удаления пользователей.

3. Проверьте параметры подключения в `server/.env`.
4. Запустите frontend и backend:

```bash
npm run dev:full
```

Или в двух терминалах:

```bash
npm run server
npm run dev
```

Backend доступен на `http://localhost:3001`, frontend — на `http://localhost:5173`.
MariaDB для этого проекта должна быть настроена на `127.0.0.1:3307`, чтобы не пересекаться с Docker-контейнером `DB-labs`, который использует порт `3306`.

**Project Planner** - это современное веб-приложение для управления задачами с использованием Kanban доски. Приложение позволяет эффективно организовывать рабочий процесс, отслеживать прогресс и управлять приоритетами задач.


## ✨ Особенности

### 📋 Управление задачами
- **4 колонки Kanban**: Очередь, В работе, На проверке, Готово
- **Приоритеты**: Низкий, Средний, Высокий (цветовая индикация)
- **Drag & Drop**: Перетаскивание задач между колонками
- **Контекстное меню**: Правый клик для быстрых действий

### 🔧 Функциональность
- 💾 **Автосохранение**: Все данные сохраняются в браузере
- 📥📤 **Импорт/экспорт**: Сохранение и загрузка задач в JSON
- ✂️📋 **Буфер обмена**: Вырезать/копировать/вставить задачи
- 🔍 **Быстрый поиск**: По названию и описанию задач
- 📊 **Статистика**: Отслеживание прогресса по задачам

### 🎨 Интерфейс
- 📱 **Адаптивный дизайн**: Работает на всех устройствах
- 🎯 **Интуитивный UI**: Простой и понятный интерфейс
- ⚡ **Быстрая загрузка**: Оптимизированная производительность

## 🚀 Быстрый старт

- Node.js 16+ 
- npm 8+ или yarn

```bash

# Запустите в режиме разработки
