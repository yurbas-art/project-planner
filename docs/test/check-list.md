# Чек-лист тестирования Project Planner

## Главная страница
- [ ] Создание задачи через кнопку "Создать"
- [ ] Редактирование задачи (клик по карточке)
- [ ] Drag-and-drop перемещение между колонками
- [ ] Удаление задачи (кнопка ✖ на карточке)
- [ ] Контекстное меню задачи (правый клик)
- [ ] Отображение приоритетов (цветовая индикация)
- [ ] Счетчик задач в каждой колонке
- [ ] Hover-эффекты на карточках

## Модальные окна
- [ ] Модальное окно создания задачи
- [ ] Модальное окно редактирования задачи
- [ ] Модальное окно настроек
- [ ] Подтверждение перед удалением всех задач
- [ ] Экспорт задач в JSON
- [ ] Импорт задач из файла
- [ ] Закрытие модальных окон (крестик, overlay, Esc)

## Работа с данными
- [ ] Автосохранение в localStorage
- [ ] Восстановление данных после перезагрузки
- [ ] Экспорт задач (скачивание JSON файла)
- [ ] Импорт задач (загрузка из JSON файла)
- [ ] Удаление всех задач через настройки
- [ ] Очистка localStorage через настройки

## Тема оформления
- [ ] Кнопка переключения темы (солнце/луна)
- [ ] Светлая тема интерфейса
- [ ] Темная тема интерфейса
- [ ] Сохранение темы после перезагрузки
- [ ] Определение системной темы

## Адаптивность
- [ ] Десктопная версия (≥1024px)
- [ ] Мобильная версия (≤767px)
- [ ] Вертикальное расположение колонок на мобильных
- [ ] Удобство touch-интерфейса на мобильных
- [ ] Отображение модальных окон на мобильных

- [ ] Работа с буфером обмена задач
- [ ] Отображение текущего времени в хедере

- [ ] Safari (если доступно)

- [ ] Создание задачи с очень длинным названием
